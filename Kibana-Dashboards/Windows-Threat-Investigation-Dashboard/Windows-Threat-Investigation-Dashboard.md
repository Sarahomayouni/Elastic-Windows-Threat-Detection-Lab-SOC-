# Windows Threat Investigation Dashboard

## Purpose

Provide SOC-oriented threat visibility and behavioral detection analytics using custom KQL and EQL detection rules built on Windows Sysmon telemetry.

The dashboard focuses on suspicious process execution, persistence techniques, command-line abuse, outbound network communication, and multi-stage attack chain detection.

## Visualizations

### Impacted Endpoints

Displays the number of systems affected by security alerts and suspicious activity.
Helps analysts quickly identify potentially compromised hosts requiring investigation.

### Total Active Alerts

Shows the total number of active detection alerts currently generated by the SIEM environment.

Provides a high-level overview of overall detection activity.

### Total Critical Alerts

Displays the number of critical severity alerts associated with high-confidence malicious activity or correlated attack chains.

### Total High Alerts

Shows high severity alerts related to suspicious execution, persistence behavior, or potential command and control activity.

### Total Medium Alerts

Displays medium severity alerts associated with potentially suspicious but lower-confidence activity.

### Total Low Alerts

Shows low severity alerts and informational detections requiring additional context or investigation.

### Alerts Timeline by Rule

Provides a time-based view of detection alerts grouped by rule name.
Helps identify attack patterns, detection spikes, and recurring malicious behavior over time.

### Risk Score per Host

Displays the aggregated risk score for each monitored host based on alert severity categories including Low, Medium, High, and Critical.

Helps analysts quickly identify high-risk systems by evaluating the total accumulated risk score per host for prioritization and investigation.

### Top Targeted Accounts

Identifies user accounts most frequently associated with suspicious activity or alerts.

Helps detect targeted accounts.

### Suspicious Outbound Connections (C2)

Monitors potentially malicious outbound network connections initiated by suspicious processes or command-line utilities.

Supports detection of possible command and control communication.

### Dropped File Extensions

Displays file extensions associated with suspicious or newly created files.

Helps identify potentially malicious scripts, executables, archives, and dropped payloads.

### Top Malicious Processes

Highlights processes most frequently associated with triggered detection rules and suspicious activity.

Helps analysts identify commonly abused binaries and attacker tooling.

### Process Tree Activity

Visualizes parent-child process relationships to support attack chain analysis and suspicious process investigation.

Helps identify malicious process spawning behavior and execution flow.

### MITRE ATT&CK Mapping

Maps triggered detection rules to MITRE ATT&CK tactics and techniques.

Provides visibility into adversary behaviors, attack stages, and detection coverage.

### Top External Destination IPs

Displays external IP addresses most frequently contacted by suspicious processes or outbound connections.

Helps identify unusual communication patterns and potential malicious destinations.

### Alerts per Host

Shows alert distribution across monitored systems.

Helps identify heavily targeted or potentially compromised endpoints.

### Severity Over Time

Provides a time-based visualization of alert severity trends across the environment.

Helps analysts monitor escalation patterns and periods of increased threat activity.

### Attack Chain Investigation Table

Displays correlated attack activity and multi-stage detection sequences.

Supports investigation workflows by connecting execution, persistence, and network-related events into a unified attack chain view.

### Active SIEM Incident Feed

Provides a live feed of active detection alerts and ongoing suspicious activity observed within the environment.

Supports real-time monitoring and incident triage workflows.
