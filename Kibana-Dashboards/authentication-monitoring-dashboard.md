
# Authentication Monitoring Dashboard

## Purpose

Monitor authentication activity across Windows systems.

## Visualizations

### Failed Logins

Displays the total number of failed authentication attempts.

### Successful Logins

Shows successful authentication activity.

## Authentication Timeline

Provides a chronological view of successful and failed authentication events.

## Top Targeted Users

Identifies user accounts receiving the highest number of authentication attempts, helping detect targeted attacks.

## Top Source IP Addresses

Displays the source IP addresses generating authentication events to identify potentially suspicious origins.

## Logon Type Analysis

Analyzes authentication methods and logon types to understand how users and systems are accessing resources.

## Failed Logins by Host

Shows systems experiencing the highest number of failed login attempts, helping identify targeted endpoints and servers.

## Top Failure Reasons

Highlights the most common authentication failure causes, such as invalid credentials, locked accounts, or expired passwords.
